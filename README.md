# Neyron Laboratoriyası

Hodgkin-Huxley interaktiv neyron simulyasiyası — fiziologiya tədrisi üçün.

## Vercel-ə necə yükləmək

1. https://vercel.com saytına daxil ol (pulsuz hesab aç)
2. "Add New..." -> "Project" seç
3. "Import Third-Party Git Repository" SEÇMƏ - aşağı bax
4. "Deploy" bölümündə bu qovluğu (zip içindəki bütün faylları) sürükləyib at
5. Vercel avtomatik tanıyır - "Deploy" düyməsinə bas
6. 1-2 dəqiqə sonra linkin hazırdır

Bu simulyasiyada nə var:
- Hodgkin-Huxley modeli (klassik kalmar aksonu)
- 3 rejim: cərəyan klamp, voltaj klamp, iki neyron sinaps
- Temperatur effekti (Q10)
- Farmakologiya: TTX (Na+ blokadası), TEA (K+ blokadası)
- Tək, cüt və qatar stimul rejimləri

tətbiq kimi açılır.
